# 🚀 DEPLOY YOUR VIDEO ENCODER BOT NOW!

## 📋 **BEFORE YOU START - Get Your 3 Credentials**

### **Step 1: Get API ID & API Hash (2 minutes)**
1. Go to https://my.telegram.org
2. Sign in with your phone number
3. Click "Create new application"
4. Fill out the form:
   - App title: `Video Encoder Bot`
   - Short name: `video_encoder`
   - Platform: `Web`
5. Click "Create"
6. **Save these two values:**
   - `API ID` (numbers only)
   - `API Hash` (letters and numbers)

### **Step 2: Get Bot Token (1 minute)**
1. Go to https://t.me/BotFather on Telegram
2. Send: `/newbot`
3. Bot name: `Video Encoder Bot`
4. Username: `YourUniqueVideoEncoderBot` (must end in `bot`)
5. **Save the BOT TOKEN** (starts with numbers, has colon)

**You now have all 3 credentials needed!** 🎯

## ⚡ **DEPLOY ON RAILWAY (2 minutes)**

### **Step 1: Create GitHub Repository**
1. Go to https://github.com/new
2. Repository name: `video-encoder`
3. Description: `Telegram bot that encodes videos without downloads`
4. Click "Create repository"
5. Upload all files from this folder to GitHub

### **Step 2: Deploy on Railway**
1. **Go to https://railway.app**
2. **Click "Login with GitHub"** (completely free)
3. **Click "New Project"**
4. **Click "Deploy from GitHub repo"**
5. **Select your "video-encoder" repository**
6. **Click "Import Repo"**
7. **Railway will automatically detect and deploy!**

### **Step 3: Add Environment Variables**
In Railway dashboard:
1. **Click on your project**
2. **Go to "Variables" tab**
3. **Add these 3 variables:**
   ```
   API_ID=your_api_id_here
   API_HASH=your_api_hash_here
   BOT_TOKEN=your_bot_token_here
   ```
   *(Replace with your actual credentials from above)*

4. **Click "Redeploy"**
